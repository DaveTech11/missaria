# 🎬 Miss Aria Movie Stream 10.3

- `/movie <title>` and `/movies <title>`
- TMDB search, movie details, poster, rating, genres and synopsis
- Nigeria-first watch-provider lookup with US fallback
- Authorized watch-options link from TMDB
- Official YouTube trailer button
- Animated streaming/search progress card
- Inline movie result selection

## Environment

Add `TMDB_API_KEY` to Render/Railway environment variables. Never commit the key.

This module does not download or redistribute copyrighted movies. It surfaces authorized viewing options returned by TMDB.
