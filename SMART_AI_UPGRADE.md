# Miss Aria — Smart AI Upgrade

Added:
- Natural-language AI help/status shortcuts.
- Shared intent detection for image, broadcast, help, status, and normal chat.
- Retry helper for transient provider failures.
- Global unhandled-rejection/uncaught-exception logging shield.
- Progress-bar helper for future AI animations.
- Natural image generation retries once before reporting failure.
- Removed duplicate natural image/broadcast handlers from bot.js so one user message does not accidentally trigger the same feature multiple times.

Run `npm install` then `npm start`.
